<objective>
Build `links_sidecar_index.py`: the persistence + freshness layer for the wikilink graph, a structural
clone of the proven `embedding_sidecar_index.py` (D-04). It builds/decodes `ops/graph/links-index.json`,
self-heals on parse failure, excludes its own path from the walk, carries unchanged notes forward by
content hash, and implements the D-04a hybrid freshness (incremental + lazy full-rebuild-if-stale) while
gracefully degrading when the sweep lock is held. It also wires a non-destructive startup rebuild into
composition.py mirroring the embedding-index startup path.

Purpose: NOTE-03 / SC-3 — `:graph`/`:stats`/`:check` are backed by a maintained sidecar, not a full
vault walk on every call.
Output: `sentinel-core/app/services/links_sidecar_index.py`, `sentinel-core/tests/test_links_sidecar_index.py`,
and a startup-rebuild edit in `sentinel-core/app/composition.py`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vault (REST) -> sidecar builder | Note bodies + a prior on-disk index file are untrusted content; the index JSON may be corrupt |
| sweep lock -> read-only command | A destructive-operation lock is shared with a read-mostly command path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-SELFHEAL | Denial of Service | corrupt links-index.json crashing the read path | high | mitigate | decode_index_body self-heals to empty dict; next rebuild repopulates — mirrors embedding sidecar contract |
| T-45-OWNPATH | Tampering | sidecar indexing its own file / recursive growth | medium | mitigate | Notes-scoped walk + explicit LINKS_INDEX_PATH exclusion guard (D-04) |
| T-45-LOCK | Denial of Service | sweep-in-progress turning :graph into a hard error | medium | mitigate | SweepInProgressError caught; serve existing stale index (Pitfall 2) |
