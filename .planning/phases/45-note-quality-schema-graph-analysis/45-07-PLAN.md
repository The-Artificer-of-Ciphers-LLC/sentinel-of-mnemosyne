| Discord user command -> gateway -> core HTTP | User-issued subcommands cross into an authenticated httpx call carrying X-Sentinel-Key |
| core JSON response -> Discord string | Route response (derived from untrusted vault content) is rendered into a chat message |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-45-GWERR | Denial of Service | gateway call failure surfacing a raw exception to Discord | medium | mitigate | try/except returns a friendly string (mirrors call_core_sweep_status); no raw stack/500 reaches the user |
| T-45-KEY | Information Disclosure | leaking core response internals into chat | low | mitigate | Formatter emits only the bounded summary keys (counts/density), not raw error bodies or auth material |
| T-45-DEAD | Tampering | stale fixed-prompt fallback silently shadowing the new path | low | mitigate | Dead _SUBCOMMAND_PROMPTS stats/check entries removed in the same change; test asserts the new gateway path is taken |
</threat_model>
