<objective>
Begin the pf2e chat handoff (D-09): wire pf2e to sentinel-core via `SentinelCoreClient` and migrate `modules/pathfinder/app/llm.py`'s chat/completion call sites off direct litellm (`acompletion_with_profile`) and onto `core_client.complete()` (POST /provider/complete). This restores the "everything through Sentinel" gateway for pf2e's largest chat surface and removes its dependence on a module-side model/endpoint for chat (SC-6).

Purpose: pf2e owns its local logic and prompt content; core owns "how do I reach an LLM." After this plan, llm.py's chat prompts are composed in pf2e but executed through core's ProviderRouter (with exo/LM Studio selection + fallback centralized). This makes pf2e's chat path depend on core at runtime — the dependency accepted in D-10, already provisioned via compose `depends_on: sentinel-core` (healthy). Embeddings stay local (Phase 43).
Output: the pf2e core-client wiring and the migrated llm.py chat call sites, with a new handoff test.
</objective>
