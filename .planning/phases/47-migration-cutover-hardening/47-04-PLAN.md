## Locked Decision (resolves RESEARCH.md Open Question Q1 — state in acceptance criteria)

**What triggers full atomic rollback (`ledger.replay`):**
1. Any hard exception escaping a REST mutation (`relocate`/`write_note`/`delete_note`/`read_note` raising, an unhandled crash, or `SweepInProgressError` raised mid-body).
2. The D-03a `:graph` post−pre orphan diff finding ≥1 NEW orphan (notes/-scoped).
3. The Track A ops-bound `scan_for_title_refs` post<pre shortfall for any moved file that could not be repaired by a backlink rewrite.

**What does NOT trigger rollback (accepted partial success — reported, never silent):**
- Individual notes-bound entries that the reused `pipeline_orchestrator.run()` requeues/dead-letters on Verify-fail (`report.verify_failed`/`report.errors` non-empty while run `status="complete"`). These stay in `inbox/` per Phase 46's designed graceful-degrade contract — a bad LLM completion is not vault corruption. Surfaced in `MigrationReport.verify_failed`.
